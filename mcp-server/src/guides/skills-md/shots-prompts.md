# 技能：分镜与视频提示词（shots-prompts）

> 适用：剧本已入库、主体已建，要把剧本变成导演台片段与可直接投喂的提示词。

## 1. 片段怎么切

- 一个连续动作 = 一个镜头；场景切换、视角大变、情绪转折 = 新镜头。
- **片段编号按集重置**：每集从 1 开始（第1集 1–N，第2集重新 1–M）；禁止全剧连续编号，episodeId 必须归到正确剧集，不得把全剧场次挂在第1集。
- 单段时长 5–15 秒（质量建议）；节点硬上限 736 帧 ≈ 30.7s@24fps。
- 时长判定：环境空镜 4–6s；单角色简单动作 5–8s；复杂动作链 8–12s；对白 = 朗读秒数 + 2s 缓冲；大幅运镜 +3–5s。
- 相邻镜头景别至少差两档（刻意匹配除外）。

## 1.5 镜头卡（每一段必须写全；借鉴 drama-skills 的分镜方法）

把每个片段当一张镜头卡，写进 `description` / `videoPrompt`（不新增字段）：

- **职责**：这镜完成什么（信息 / 权力 / 情绪 / 空间 / 节奏），删掉它剧情是否受损；
- **来源**：剧本场次 ID + 本镜动作或声音短引文；整集**每一场都要有镜头承载**，确需省略在开头写「未拍场次：<场次 ID>（理由）」；
- **时长**：按发声 / 动作时间估，不按剧本字数折算；对白 = 完整发声 + 停顿 + 末尾反应；
- **景别 · 机位 · 运镜**：每镜一个主运镜，「固定」也写理由；
- **起点 → 唯一动作 → 终点**：人物、双手、持物状态转换写清（交接 / 换手 / 放置 / 取回不许镜外瞬移）；
- **声音**：同期声 / 对白 / VO 的时间与来源；
- **视觉依据**：引用主体库「主体 / 状态」名称（哪个状态、控制什么范围）；
- **参考图**：真实可读的 storageKey；缺图写 PLAN 槽位并列进缺图清单。

**先写场次站位，再写镜头**：固定锚点、各人相对锚点的位置、轴线与摄影机工作侧、哪一镜改变站位；再逐镜锁朝向 / 视线 / 持物 / 出入口。

切镜必须带来信息、权力、情绪、空间或节奏变化；同义重复删；同一动作不跨镜重复；终点必须能成为下一镜可信起点。
**起始帧只写起点可见内容**；终点状态另写（收尾关键帧），不要把终点写进起始帧提示词。

`split_script_to_shots` 的草案只是骨架：必须按镜头卡重设 description / 时长 / 景别（`set_shot_prompt`），
不得直接 confirm 后就出片。

## 1.6 运镜与叙事必须按「题材 + 风格」分层（2026-11-19 用户要求）

同一套剧本，不同题材的运镜语法不同，不许所有项目都用一套通用写法：

| 题材 | 运镜语法 | 叙事骨架 |
|---|---|---|
| 都市异能 / 犯罪悬疑 | 手持 + 越肩 + 长焦压迫 + 暗部藏人；一镜一个信息点 | 信息差 → 反转 → 代价；动作戏拍「打点」不拍全身乱舞 |
| 古装 / 武侠 | 横移 + 环绕 + 升降大远景交代空间；交手用短切 + 局部特写 | 势力亮相 → 试探 → 破局；招式为剧情服务，不为炫技 |
| 科幻 / 末世 | 广角低机位 + 固定机位观察 + 对称构图；运镜少而重 | 世界观先立 → 危机触发 → 规则反噬 |
| 恐怖 / 惊悚 | 固定镜 + 缓推 + 视点切换（POV）；禁止提前给完整主体 | 预期违背 → 逼近 → 延迟揭晓 |
| 合家欢 / 萌宠 | 平视 + 轻跟 + 浅景深特写 | 小目标 → 小挫折 → 温暖结果；不写死亡与伤残 |

- 运镜不是越多越好：一镜一个主运镜，「固定机位」在科幻 / 恐怖里是合法选择。
- 先写**调度**（谁在哪、朝向哪、做什么、停在哪），再写**机位**；顺序颠倒必出「飘」的片子。
- 相邻镜的轴线 / 视线 / 持物方向必须连续；越轴必须靠一次可见的调度动作交代。

## 1.7 风格有争议时必须问，不许默认

- 同一段剧本可能同时成立「古装写实」与「古装动画」，或「科幻 3D」与「水墨科幻」；
  这类**不是小偏好**，会改构图、机位、段长与材质，必须先把 2–3 个候选（含风格组合技）报给用户选。
- 风格组合技（`list_style_presets` 的 `combo` 分类）：科幻 3D + 超写实 PBR、动漫造型 + PBR 材质（皮克斯向）、
  实拍摄影 + 电影胶片、赛璐璐 + 电影光、定格 + 实物微缩、水墨 + 体积渲染。
  组合技是一整套写法：材质、光影、颗粒、反射都要跟着改，不是末尾加一句话。
- 用户没说风格时，先给「题材推断 + 2 套候选 + 影响」，等答复；用户说「你定」才按题材默认。
- 剧本本身没定稿（场次缺、结局未定、主体未完善）时，不写分镜提示词——先回去补剧本 / 补主体图。

## 1.8 质量门是工具，不是口号（硬门禁）

- 写完提示词必须跑 `review_shots({ projectId })`：逐片段 0–10 分，报 error/warn 与 fix。
- **低于 7 分或存在 error 时不许出片**：`request_director_run` 会直接返回 `QUALITY_GATE_FAILED`；
  `apply_shot_prompts` 在剧本未入库时返回 `SCRIPT_NOT_READY`。
- 修复顺序：补主体图 → 改提示词（`set_shot_prompt`）→ 重跑 `review_shots`；不要靠重试绕过。
- **用户权限高于质检门**：用户看过结果并明确说「这样可以」时，带 `userOverride:true` 放行，
  但必须把「哪些项未过线、用户已知情」原样回报，不许把 override 当成默认路径。

## 1.9 风格切换 ≠ 只加一行（2026-11-13 用户指出）

导演风格决定构图、机位与镜头长度：韦斯·安德森是对称长镜，王家卫是手持碎片短镜，
诺兰是 IMAX 广角长镜——不可能共用同一套提示词和段长。

- 切换风格后必须**重写**每段的 imagePrompt / videoPrompt 与建议时长（`set_shot_prompt`），
  不要只在末尾追加一句「风格：…」。
- 导演台风格参数（`sharedParams.stylePrompt`）只负责生成时拼接；提示词本身仍要按新风格重写。
- 先向用户确认「只换风格 / 连提示词和时长一起重写」；用户选后者再批量改，不要静默覆盖。

## 2. 提示词体例（无旁白版，H3 Ref2VA 单块中文版）

每段两轨：

- `imagePrompt` = **参考绑定 + 本镜内容**，不是人物小传，也不是主体名重复表。逐槽位只写一行，按主体类型选句型：
  - 角色：`<Subject N> 是角色名，取自 @PictureN（定妆/状态图）：只锁身份，不描述外貌；姿势与构图随本段调度。`
  - 场景（本段无角色）：`<Subject N> 是本段场景，取自 @PictureN（概念图）：以该图为画面基准，锁建筑形制、地平线、机位与构图。`
  - 场景（本段有角色）：`<Subject N> 是本段场景，取自 @PictureN（概念图）：锁建筑形制、地平线与光位；构图随角色调度。`
  - 道具：`<Subject N> 是本段道具，取自 @PictureN（道具图）：锁形制与材质。`
  - **禁止**：在定义里复述角色外貌（不写脸/发型/身材/服装的具体描写，也不要写「不得改写外貌/发型/服装/体型」这类否定句——模型照样会去画）；禁止再追加一行 `主体锚定：<Subject 1>=…` 重复映射；禁止写「凡正文出现其中任一主体，即按该图锁形制、不锁构图」这类汇总句。
  - 可抄骨架（照抄结构，只替换内容；不许改写成一段形容词）：
    ```
    subject_definitions:
    <Subject 1> 是本段场景X，取自 @Picture1（概念图）：锁建筑形制、地平线、机位与构图。
    <Subject 2> 是角色Y，取自 @Picture2（状态图）：只锁身份，不描述外貌；姿势随本段调度。
    detailed_description:
    画面为干净画面：无字幕、无字卡、无屏显文字、无水印、无标志；所有台词仅为声音。
    [Shot 1] 中景，固定机位缓慢推近，机位在X一侧、轴线固定。空间调度：<Subject 2> Y 走到窗边、侧脸贴玻璃停住。<Subject 1> X 为空间基准。声音：风声与布料摩擦。
    overall_soundscape:
    本段仅环境声与动作音效：风声、脚步与器物轻响。全段无人旁白；Y 双唇紧闭。
    non_diegetic_music:
    无叙事性音乐。
    ```
  - 写之前先回答三问：本段有没有角色 → 每个槽位是场景/角色/道具 → 这镜必须锁什么、可以让什么变。三问不清就不要写。
- `videoPrompt`：五段式正文——
  ```
  画面为干净画面：无字幕、无字卡、无屏显文字、无水印、无标志；所有台词仅为声音，绝不渲染为画面文字。
  [Shot 1] <景别·角度·运镜·焦段·景深>。<空间锁定一句>。<主体动作，带终点态>。声音：<同期声>。
  旁白/台词只进 <d>[Chinese] …</d>，描述里不重复。
  ```
  首帧只在用户明确要求锁首帧时才写「以 @PictureN 为首帧」；否则场景图锁构图、角色图只锁身份，不要把所有参考都写成首帧。
- `negativePrompt`：只写本镜真实风险的实例（no plastic, no wristwatch, no printed logos），不写「no modern objects」这种范畴词。
- **每个挂了参考图的槽位，正文都必须至少出现一次 `<Subject N>`**（首次提到该主体时写成 `<Subject N> 名字`）。
  只写 `<Subject N> 是…` 的定义、正文里却只用名字，引擎会当成没这张图——人和道具直接不锁形制。
  `validate_project` 会对「槽位有图、正文无 <Subject N>」直接报错。

## 3. 十二条铁律（输出前自查）

1. 叙事功能优先：没有叙事功能的镜头删掉。
2. 先调度后构图：先定身体在空间里做什么，再放机位。
3. 每镜头一个主运镜；「不运镜」是合法选择。
4. 每个动作有终点态（「转身直到侧脸贴上窗边，停住」）。
5. 写行为不写情绪；恐惧写成眼神/呼吸/手。
6. 连续性靠工程：身份、服装、光位方向、年代、地点，同场景逐字重复。
7. 关键帧是控制点：先修静帧，再花视频额度。
8. 匹配模型控制面，不要向模型要它没有的能力。
9. 负面词指名实例。
10. 一次只套一个风格。
11. 要一条就给一条 + 至多三行理由。
12. 旁白不进视频、音频不带人声（H3 会把人声对到角色嘴上）。

## 4. 质量门（低于 7 分重写）

叙事功能 / 空间可读 / 动作终点 / 镜头语言一致 / 连续性 / 负面词有效 / 时长合规 / 台词规范 / 声音设计 / 无形容词汤——逐项 0–1 分，总分 <7 不许交付。

## 5. 落地

0. **没有现成提示词时（从零）**：`scaffold_episode({ style:{look,aspect}, durationSec, sharedParams })`
   —— 工具按剧本场次建占位主体 + 占位片段 + 按槽位约定生成提示词，并返回 `missingAssets`；
   把缺图清单原样交给用户（哪些角色要定妆图、哪些场景要轴图），由用户出图或用画布生成后导入。
1. **素材到位后**：`apply_shot_prompts({ style })` 按片段 references 的真实槽位重写提示词，
   `<Subject N>` → `@PictureN`；N 必须等于 references 里同类素材序号（引擎把第 N 张落成 PictureN）。
2. 手工微调才用 `set_shot_prompt`；不要整段重写工具已生成的骨架，改动作/声音即可。
3. 收尾用 `get_workbench` 核对：每段有 imagePrompt、有 references、时长与分镜一致。

## 6. 交付前审查（照 drama-skills 的 review 清单，只报事实 + 修法）

- 每场有镜头承载；每镜有职责 / 起点 / 唯一动作 / 终点 / 声音 / 视觉依据 / 参考图；
- 无同义重复镜头；相邻镜朝向 / 视线 / 持物 / 光位连续；起始帧不含终点状态；
- 每段 imagePrompt / videoPrompt 非空，无「待补 / 按剧本 / 占位」字样；
- 时长落在约束内（17k+5 帧吸附、每段 ≤736 帧、单段建议 5–15s）；对白按发声估时；
- 参考图清单：哪些已有、哪些缺；缺图原样交给用户，不要静默改文生视频；
- 质量门 <7 分重写（延续第 4 节）。
