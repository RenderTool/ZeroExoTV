# 场景一个地点一个主体；一个角色一个演员；片段可改分集

## 一、用户原话

> 我不明白这种低级错误为什么会发生？你就是这样设计垃圾糊弄我？
> 另外我说了场景不同地点算一个主体！为什么 MCP 处理的仍然是错误的？？？
> 甚至出现一个主体出现两个明显不一样的主演？

## 二、根因（设计问题）

- 之前只在技能里「建议」主体粒度，MCP 没在写入/交付时强制，也没提供归并工具；
  Agent 按房间/楼层把场景拆成 37 个主体，产品只能如实展示。
- 角色挂图只校验「看过图 + 有反推 prompt」，没校验「同一张脸」；不同演员的图可以挂进同一主体。

## 三、改造

### 场景：一个地点/建筑 = 一个主体

- 新增 `consolidate_scenes({ projectId, baseVersion, dryRun, userConfirmed })`：
  - 按地点键归并（云顶大厦宴会厅 / 28 层总裁办公室 / 保安部 → 云顶大厦）；
  - 子区域变成 target 的状态，各自保留提示词与图（`merge_subjects` 新增 `asState`）；
  - 先 dryRun 把分组给用户看，确认后才落盘。
- 技能/模块规格/instructions 写死：**场景 = 地点**，子区域是状态；提取完主体后先 `consolidate_scenes` 再给用户看清单。

### 角色：一个角色主体只能一个演员

- `set_subject_image` 新增门槛：角色已有多张图时，再挂新图必须 `samePersonConfirmed:true`
  （先看图比脸型/五官/年龄/发型）；不一致 → 停，建两个主体。缺了返回 `IDENTITY_CONFIRM_REQUIRED`。
- 技能写死：同一演员不同造型 = 状态；不同演员绝不进同一主体。

### 导演台：默认第一集，其它集为空（不做片段搬迁）

- 旧片段没有 episodeId 时，自动归到**第一集正片**（跳过故事大纲类条目）；默认打开第一集，不是「未分集」。
- 分集下拉列出全部集，空集可切换；切到空集显示「本集还没有片段」+ 新建片段，不再把别的集片段带过来。
- 不做「本段所属 / 归入本集」这类搬迁 UI（用户明确不要）。

## 四、边界

- `consolidate_scenes` 的自动分组按地点关键词/分隔符；误分时先 dryRun 看分组，不要直接落盘。
- 身份门槛是「确认」不是人脸识别；Agent 必须真看图，不能瞎传 true。
- 旧项目 37 个场景不会自动变，需 Agent 调 `consolidate_scenes` 归并（用户确认后）。
