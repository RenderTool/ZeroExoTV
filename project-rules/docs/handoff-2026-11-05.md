### Bug 2 · `Failed to execute 'removeChild' on 'Node'` 崩溃（复发两次）

**现象**：提示词输入区操作后报 `The node to be removed is not a child of this node`。

**修过的**
- 第一轮：`mention-editor.tsx` 的 `handleKeyDown` 兜底分支用 `chip.remove()` 在 React 树外删节点 → fiber 仍持有引用 → 下次 reconcile 抛错。改成序列化 DOM + 算光标 idx + `onChange` 受控重渲染。
