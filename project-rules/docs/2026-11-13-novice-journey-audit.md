# 小白用户旅程 · 漏洞审计（2026-11-13）

> 视角：第一次用、不懂 MCP、不懂镜头术语的用户。目标不是「发现问题后问 Agent」，
> 而是软件在创建 / 打开 / 交付三个时刻自己补缺，或明确挡住「完成」。

## 一、旅程与漏洞

### 1. 第一次打开 / 新建项目
- 没授权数据目录：已有 RootGate 引导，不属本次。
- 新建项目后：画布/剧本/主体/导演台都是空态。**漏洞**：空态只说「暂无」，不告诉下一步。
  → 主体空态改为「可以让 Agent 从剧本里提取主体，也可以手动添加」。
- 没有剧本时点主体/导演台：已有「先去剧本」类提示；保持。

### 2. 导入剧本（MCP / 页面）
- 旧流程只写正文、不写「本剧信息」：页面「本剧信息」空白，用户不知道要不要填。
  → MCP `ensure_project_ready` 交付前从第一集正文提炼一句简介；`audit_upgrade` 也能查出来。
- 英文/外部平台原文未确认格式：已有 `preflight_import` + `sourceFormatConfirmed` 闸门。

### 3. 主体（最容易被用户判死刑的地方）
- Agent 只 `upsert_subject` 不跑 `set_subject_profile` → 主体有名字、没提示词。
  → MCP `upsert_subject` 新建/空树时立刻补**最小可用提示词**（`promptSeeded`）；
  → 前端打开主体时，空基础状态提示词自动补模板；
  → 主体列表顶部「项目体检」：有 N 个主体没提示词 → 一键「补上」。
- 主体没图：列表卡片显示「暂无封面图 · 点开可生成」；体检条提示「N 个主体还没定妆图」。
- 全剧风格没设：体检条「还没设全剧风格 → 选择风格」，直接打开画廊（不用先去本剧信息）。
- 旧数据提示词里还有「按剧本…定 / 待补」：`audit_upgrade` 的 `PROMPT_PLACEHOLDER` 查出来；
  设全剧风格后统一改写。
- 主体图没有反推 prompt：`audit_upgrade` 的 `SUBJECT_IMAGE_NO_PROMPT` 查出来，提示重新挂图。

### 4. 导演台 / 拆分镜
- 多集项目的片段全平铺：新 UI 按 `episodeId` 分组；旧数据落「未分集」桶，`audit_upgrade` 报
  `SHOT_EPISODE_UNASSIGNED`。
- 空集：分集下拉列出全部集，空集置灰「0 段」，避免切过去看不到东西。
- 片段没写提示词：导轨「检查」按钮用大白话报「还没写画面提示词 / 还没写视频提示词 / 还没有参考图 /
  时长不在 5–15 秒」，点「定位」跳过去。
- 时长/延续法：已有 `plan_continuity_edit` + `run_generation` 硬闸门，不满足直接拒绝，不会静默出碎段。

### 5. 交付
- Agent 说「完成」但还有空：`ensure_project_ready` 交付前自愈 + 返回大白话 summary；
  server instructions 要求必须在「完成 / 可以出片」前调用。
- MCP 版本旧、缺工具：`_mcpOutdated` + `mcp_update_status` + `update_mcp_server`；更新后必须
  `audit_upgrade` 并问用户是否修复，不能只说「版本已更新」。

## 二、现在软件保证什么

| 时刻 | 保证 |
|---|---|
| 新建主体 | 一定有提示词（最小可用），不会再出现空白主体 |
| 打开主体 | 空提示词自动补模板并落盘 |
| 主体列表 | 顶部体检：缺风格 / 缺提示词 / 缺定妆图，能补的一键补 |
| 导演台 | 按集切换；「检查」用用户语言报缺什么，点定位 |
| 交付前 | `ensure_project_ready` 补主体提示词 + 本剧简介，并报告还缺什么 |
| 升级后 | `audit_upgrade` 只读扫旧流程 7 类缺口，Agent 必须报给用户并询问修复 |

## 三、仍不自动做（必须用户/Agent 决定）

- **不自动生成图片**：主体定妆图/参考图要用户选模型与参数后生成（画布生成）。
- **不自动写创作内容**：分镜提示词、剧情、台词仍由 Agent 按技能写；软件只查缺、不代写。
- **不判断剧本好坏**：剧情/结构问题不在结构审计范围。
- **旧项目数据不静默迁移**：`audit_upgrade` 报缺口，用户确认后再修。

## 四、界面文案红线

- 用户界面禁止出现：`sceneId` / `camera` / `sound` / `REF-` 槽位语法 / `SHOT_PROMPT_EMPTY`
  这类错误码或字段名。
- 空态必须给出**下一步动作**（按钮或一句可执行的话），不能只写「暂无」。
- 能一键补的，不要求用户理解原理；补之前只需说「补什么」，不解释实现。
