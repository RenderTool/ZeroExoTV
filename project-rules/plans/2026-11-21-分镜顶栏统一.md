# C-18 分镜顶栏按统一口径改版（切集第一项 / 左侧操作 / 右侧纯统计）

日期：2026-11-21
用户口径：「分镜这些按钮要不要和剧本一样统一放顶部？位置规则基本一致？第一项都是切剧集？实现相对统一风格？」→ 采纳，并落成同一套槽位规则。

## 统一规则（已同时适用于剧本 / 分镜）
1. 单行顶栏：`data-toolbar-zone="left"` 操作、`right` 纯统计。
2. 左侧槽位固定：① 切集（永远第一项）→ ② 主动作 → ③ 编辑类（撤销/重做/版本）→ ④ 视图类（显示标签/问AI）。
3. 右侧只读统计：剧本=字数/总页数/总时长；分镜=主体数/剧集数。
4. 关闭固定右上角（embedded 由页签 X 关闭）。
5. 分镜生产台内部的侧栏/时间轴工具不上顶栏（属于工作区工具）。

## 本次改动（`storyboard-fullscreen-editor.tsx`）
- 移除 antd `Select 180px`，换成复用 `FullscreenDropdown` 的「当前集标题 + ▾」按钮（`data-storyboard-episode-switch`），与剧本切集控件同形态；作为左侧第一个操作。
- 「重新生成该集」从裸图标按钮改为 `Button type=text` 图标 + 文字（`data-storyboard-regenerate`），位于切集之后。
- 新增右侧统计区 `data-storyboard-stats`：主体数（productionItems.length）+ 剧集数；只读、零按钮、右对齐。
- 分隔线/配色沿用工具栏 token（`theme.toolbar.border`）。
