# C-15 LoRA 纯可选：不勾 = 一条都不加（取消隐式默认 turbo）

日期：2026-11-21
用户口径（原话）：「不勾选 lora 就不会用调用，一切以勾选为准！！我们默认参数也是空值才对！！……有可能本机没有这个 lora，我们也不做强制要求，因为 lora 是可选项，但我们仍然标注一些推荐 lora。」

## 规则
1. LoRA 列表照常加载（本机 models/loras 全清单，缺文件也列出来可复制文件名）。
2. **不勾任何一条 = 一个 LoRA 字段都不下发**，插件完全不加 LoRA，MODEL 直接进采样。
3. 不强制用户选，也不因「本机没这个文件」报错或阻塞。
4. 清单里把 `minimax_h3_ref2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors` 标「默认推荐」，并在列表下写一行推荐字样（只是建议，不勾不生效）。

## 改动
- 插件 `__init__.py`：`_resolve_loras` 去掉「空 → 模板默认 turbo」兜底，空列表/空字段 → `[]`；两处 `lora_name` 空值回填删除；`PARAM_SCHEMA`/`TEMPLATE_DEFAULTS` 的 `lora_name` 默认改 `""`。
- 模板 `templates/reference_video.json`：25 号 `ZeroExoLoraChain` 的 `loras` 默认 `""`（不勾 = 空文本 = 原样透传）。
- 网页 `director-plugin-payload.ts`：合并完参数后，若 `shared.params.loras` 为空且旧字段 `lora_name` 也为空 → 删掉 `loras/lora_name/lora_strength` 三个键（老项目只有 `lora_name` 时仍按他那一条跑）。
- 网页 `director-lora.ts` / `director-lora-bridge.ts`：删除 `isImplicitDefaultLoras` 与 `normalizeSelection`（「恰好一条默认推荐」不再被归一成空 —— 用户勾了它就是真选择）。
- `model-mapping-modal.tsx`：提示改为「LoRA 是可选项：不勾就完全不加 LoRA……清单里的『默认推荐』只是建议，不勾不会自动启用」，并在下方单列一行推荐名称。
