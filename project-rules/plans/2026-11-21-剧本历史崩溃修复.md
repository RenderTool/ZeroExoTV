# C-16 修复：点「剧本 → 版本」历史面板白屏（Cannot read properties of undefined (reading 'map')）

日期：2026-11-21
报障：用户点击剧本历史（剧本编辑器工具栏「版本」）直接报 `Cannot read properties of undefined (reading 'map')`。

## 根因
`script-snapshot-panel.tsx` 里 `entityText()` / `entityChars()` 直接 `entity.episodes.map(...)`。
快照列表来自 `listSnapshots()`（磁盘 JSON + 老 `backups/` 一次性迁移），老条目实体结构不统一：
- 老格式可能就是裸 `{ content: '...' }`（没有 `episodes`）；
- 迁移/损坏条目可能缺 `entity` 或只有 `title`。
一旦列表里有一条这种结构，渲染第一行就抛 `.map` of undefined，整块面板崩掉。

## 改法
- 新增 `episodesOf(entity)` 统一兜底：
  - `entity.episodes` 是数组 → 直接用；
  - 否则若是 `{ content: string }` → 当成单章节；
  - 否则（缺 entity / 缺字段）→ 空数组。
- `entityText` / `entityChars` 全部走这个函数，`content` 非字符串按空串处理。
- 语义：坏条目照常显示（0 字），不阻塞面板打开，也不静默丢其他快照。

## 验证
- `vitest script-snapshot-panel.test.tsx`：12/12（新增回归：三条快照分别是「裸 content / entity undefined / 只有 title」，面板正常渲染 3 行、裸 content 可预览出正文）。
