# C-29 服务面收敛与解耦：用户只感知 MCP + ComfyUI

日期：2026-11-22
用户拍板：正常用户感知只有 2 个端口——MCP 与 ComfyUI（ComfyUI 未来可能是云 API）。MCP 要写，但必须解耦；后续做"账户 + 云数据服务"时要能直接通过 API 接。必须先把边界设计清楚。

## 一、用户感知面（只允许这两样）

| 面向用户的东西 | 现在的形态 | 未来形态 |
|---|---|---|
| MCP | 一个进程、一个端口 `8787`，同时提供 `/mcp`（Agent 工具）与 `/tasks`（任务心跳） | 同一个入口，内部换云客户端 |
| ComfyUI | 本机 `127.0.0.1:8188` | 云 API 地址 + key |
| 网页 | 浏览器里的页面，不是服务、不开端口 | 同一份代码，可指向云 |

被删除的第三样：`8790` 文件服务。它从未出现在任何用户界面上，用户以为只有 MCP——这就是"不可见服务"，必须消失。

## 二、四条解耦边界

1. **网页 ↔ 存储（StoragePort）**
   网页只调一组读写接口（readFile/writeFile/listDir/stat/remove）。现在实现 = 浏览器目录授权（File System Access）。未来实现 = 云端数据 API（带账号 token）。网页里不得出现"服务在线/离线"概念，也不得有端口。

2. **网页 ↔ 任务（TaskPort）**
   只调 `/tasks` + `/tasks/events`（提交、查询、取消、订阅进度）。现在指向 MCP 的 `8787`；未来可整体指向云端任务 API。MCP 没开 → 任务区显示"未启动"，其余页面不受影响。

3. **MCP ↔ 存储（DataStore）**
   MCP 的工具层只依赖 `DataStore` 接口（读任务、写产物、列项目）。现在实现 = 本地数据根路径（`ZEROEXO_DATA_ROOT`，默认 `D:\Test`，本项目 `D:\ZeroExoFinTest`）。未来实现 = 云数据服务 HTTP 客户端 + 账号凭据。工具层代码不动。

4. **MCP ↔ 出片（ComfyClient）**
   只依赖 ComfyUI HTTP 客户端。现在 = `127.0.0.1:8188`；未来 = 云端地址与鉴权。切换只改 endpoint 配置。

## 三、已落地（本轮）

- MCP 的 `--http` 端口同时提供 `/mcp` 与 `/tasks*`（`handleBrokerRequest` 前置），不再需要独立文件服务端口。
- 删除了 `--http` 模式下额外监听 fs REST 端口的逻辑（原 8790 那条）。
- 网页任务客户端 `brokerBase()` 改为指向 MCP（`MCP_HTTP_URL` 去掉 `/mcp`），不再读 `httpFsInfo`。
- MCP 统一端口 **8787**（网页默认、IDE 配置、引导文案一致）；8899 不再使用。
- 验证：`GET /tasks?projectId=YqzOHlpnmUzr` → 200；`POST /mcp` initialize → 200。

## 四、待落地（下一步）

**网页去服务化**
- 删除 `src/platform/http-fs.ts`（探测、baseUrl、origin 标记、服务端数据根切换）。
- `fs.ts` 收敛为单一分支：`DataRootState = 'ok' | 'unauthorized'`；所有读写去掉 `httpFs` 分派与 `httpFsReady` 前置 await。
- 删除 `ServiceOfflineGate.tsx`；`DataRootRecoverGate` 去掉 offline 模式。
- `app.tsx` 去掉 `serviceOffline` 状态与门。
- `boot.ts` 去掉启动探测；`main.tsx` 改 `Promise.race([bootReady, 1s])`；`index.html` 加深色启动占位。
- `MaterialGroup` 去掉"数据服务离线"分支。
- `onboarding-guide` 的"换数据目录"改为重新授权（`pickRoot`）。

**工程侧**
- 删除 `vite.config.ts` 的 `zeroexo-fs-server` 插件、`tools/start-fs-server.mjs`、根 `package.json` 的 `fs` / `fs:build`。
- 删除 MCP 的 `--fs-server` 分支与 `file-server.ts` 中文件读写 REST（保留 `ensureFsRoot` 与 broker 挂载）。
- 一次性清理 localStorage 残留：`zeroexo.dataRootOrigin`、`zeroexo.httpFsBase`、`zeroexo.dataRootPath`。

**为将来云化预留（只留接口，不实现）**
- 网页侧把存储访问收敛到一个 `StoragePort` 模块出口（现在内部就是 FSA），避免后续替换时改遍全仓。
- MCP 侧把数据根访问收敛到 `DataStore`，云实现留空。

## 五、验收

- 机器上只跑 MCP(8787) + ComfyUI(8188) + 网页(开发期 5180)，无 8790。
- 全关 MCP 与 ComfyUI：网页正常打开、编辑、存盘，无白屏、无全屏拦截。
- 只开 MCP：任务中心可用，进度心跳正常。
- 只开 ComfyUI：可出片，任务进度按插件任务表轮询显示。
- `tsc --noEmit` 零错误。
