# C-13 插件 ZIP 带版本号 + 官网标注插件版本（2026-11-21）

## 1. 用户口径

> 我希望以后下载的插件 zip 带上版本号！！官网也要明确标注插件版本

现状问题：`public/downloads/ComfyUI_ZeroExoNodes.zip` 文件名不带版本，用户下完不知道是 0.1.2 还是 0.1.4；
页面上也没有一处写「官方插件版本」，连接面板只在「低于官方」时才提示，且官方版本常量还停在 0.1.2。

## 2. 方案

### 2.1 打包（新增 `tools/build-plugin-zip.mjs`）

- 读 `comfyui-plugin/ComfyUI_ZeroExoNodes/__init__.py` 的 `PLUGIN_VERSION` 作为唯一版本来源；
- 用 `Compress-Archive` 打 `public/downloads/ComfyUI_ZeroExoNodes-<ver>.zip`（zip 内顶层目录仍是 `ComfyUI_ZeroExoNodes/`，解压路径不变）；
- 同时写一份无版本副本 `ComfyUI_ZeroExoNodes.zip` 作为「最新」兼容入口（历史链接不 404）；
- 清理旧版本 zip（只留当前版本 + 无版本副本），避免仓库里堆垃圾；
- 接进 `tools/bump-version.mjs`：以后每次发版自动重打，杜绝「代码 0.1.4、zip 还是 0.1.2」。

### 2.2 官网/网页标注

- `src/features/canvas-tabs/plugin-version.ts`：`OFFICIAL_PLUGIN_VERSION` 0.1.2 → **0.1.4**；导出 `PLUGIN_ZIP_FILENAME`。
- 「使用指引」第三步：按钮文案带版本（「下载插件 ZIP（v0.1.4）」），href 指向带版本的文件名，旁边常显 `插件版本 v0.1.4` 标签。
- 「连接配置」：连上插件后常显一行 `插件版本 v0.1.3 · 官方 v0.1.4`（`data-testid="comfyui-plugin-version"`）；低于官方时保留原有黄色提示。

## 3. 验证

- `node tools/build-plugin-zip.mjs` → 产物名含版本，解压后目录结构正确；
- `tsc --noEmit` 通过；`comfyui-connect-button.test.tsx` 仍 7/7（新增断言不破坏既有）。
- 手测：使用指引第三步显示 v0.1.4，下载得到的文件名带 `-0.1.4`；连 127.0.0.1:8188（本机 0.1.3）时显示「插件版本 v0.1.3 · 官方 v0.1.4」。

## 4. 边界

- 不发版、不推送（用户明确要求本轮只在本地测）。
- zip 仍然只有插件本体（`comfyui-plugin/ComfyUI_ZeroExoNodes` 全量，不含仓库其它内容）。
