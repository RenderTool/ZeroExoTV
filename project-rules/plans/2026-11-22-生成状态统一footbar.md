# Plan：生成状态统一成「节点内一条 footbar」

日期：2026-11-22
状态：待用户拍板后实施

## 1. 现状（为什么按钮这么多）

同一个"取消/失败"动作现在散在三处，各写各的样式与文案：

| 位置 | 文件 | 现状 |
| --- | --- | --- |
| 节点内容层 | `packages/plugins/nodes/src/base-node-view.tsx`（AIStateView loading 分支，533 行起） | 生成中在节点中间/右下角画一个「取消」圆角按钮 |
| 提示词底栏 | `src/features/tools-dock/node-generate-dock.tsx`（运行中粉色按钮） | 生成中再给一个「停止」按钮 |
| 占位卡片 | `packages/plugins/nodes/src/nodes/ai-placeholder-node-view.tsx` | generating 时（仅分镜）画「停止」；error 时画「重试 + 取消」两颗 |

所以一次取消，用户可能同时看到三个可点的按钮；取消失败后还会多出一张红错卡带两个按钮。文案也没有统一来源：`网络错误`、`本机图像作业已取消`、`生成失败：生成失败` 各自拼。

## 2. 目标

一条**节点内 footbar**接管所有生成态的表达与操作，节点中部不再放按钮，底栏不再放停止按钮。

```
┌─────────────────────────────┐
│          （节点内容）        │
│                             │
├─────────────────────────────┤  ← footbar，高 28px
│ ● 生成中 4/25   QwenImage2.1     取消 │
└─────────────────────────────┘
```

- 左：状态点 + 状态文案（生成中 / 已取消 / 失败原因 / ComfyUI 无响应 / 排队中）
- 中：进度（step/total、段进度、或排队位次）；没有进度就留空，不编造
- 右：**同一时刻只有一个动作**——生成中=取消；失败=重试；已取消=无按钮（去底栏重新发送）

## 3. 状态机（唯一事实来源）

```
idle → submitting → queued → running → done
                        ↘ canceling → canceled（回到 idle 视觉，保留提示词）
                        ↘ error（带原因，可重试）
```

文案映射一处维护（新文件 `generation-status.ts`）：

| state | footbar 文案 | 动作 |
| --- | --- | --- |
| submitting | 提交中… | 取消 |
| queued | 排队中 · 第 N 位 | 取消 |
| running | 生成中 4/25 · 模型名 | 取消 |
| canceling | 正在停止… | 禁用 |
| canceled | 已取消（提示词已保留） | 无（2s 后淡出成 idle） |
| error | 失败：人话原因（网络/显存/插件无响应） | 重试 |
| done | 完成 · 3.2s | 无 |

## 4. 取消语义（延续本轮已修的逻辑）

- 取消 = **回滚到提交前**，不是失败：占位卡移除、提示词/模型/参数写回源节点、选中态回源节点。
- 取消**不清空** `data.prompt`；底栏因此永远显示刚提交的那句话。
- 取消后不再生成 error 卡，所以不会有第三组「重试/取消」按钮。
- 本机 ComfyUI 抛的 `xx作业已取消` 一律识别为取消，不当网络错误。

## 5. 落地清单

1. 新建 `packages/plugins/nodes/src/generation-status-bar.tsx`：footbar 组件（纯展示 + 一个动作回调）。
2. `base-node-view.tsx`：移除 loading 分支的居中「取消」按钮，改为底部 footbar；`AISkeleton` 保留。
3. `ai-placeholder-node-view.tsx`：generating 不再画「停止」，error 不再画「重试/取消」，统一走 footbar。
4. `node-generate-dock.tsx`：运行中不再渲染停止按钮（避免第二个取消入口）。
5. 新增 `src/shared/generation-status.ts`：state → 文案/颜色/动作的单一映射，三处共用。
6. 取消回滚逻辑收敛到一处函数（当前 `ai-generation.ts` 与 `use-agent-bridge.ts` 各有一份，合并后两处调用）。

## 6. 验收

1. 生成中，整个界面上只有**一个**取消入口（节点 footbar）。
2. 取消后：占位卡消失、源节点选中、底栏提示词仍是刚提交的那句。
3. 失败时只有 footbar 一个「重试」，不再出现红错卡双按钮。
4. 本机 ComfyUI 断开时 footbar 显示「ComfyUI 无响应」，而不是网络错误。
5. 导演台片段卡不受影响（它们是另一套 workbench 渲染，不共用这个 footbar）。
