# C-22 模板占位符残留（ComfyUI 里显示 NaN / 下拉红框）

## 用户问题

> 我打开你的模板工作流发现参数是这样的，你实际调用也是这样嘛？还是说这些 NAN 你都会覆盖一次？？

截图 `PixPin_2026-11-21_23-49-20.png`：`ZeroExo参考视频` 节点里
`width / height / frames / frame_rate / steps / cfg / seed` 显示 `NaN`，
`sampler / scheduler / cache_frames_codec` 下拉红框，`prompt / negative_prompt / guide_frames` 是 `__zx:*__`。

## 结论（先取证后动手）

1. **UI 里的 NaN 不是执行值**。`templates/reference_video.json` 第 62-83 行这批字段的值本身就是字符串占位符 `__zx:width__` 之类，ComfyUI 前端把它塞进 INT widget 只会显示 `NaN`；下拉红框是同原因——`__zx:sampler__` 不在选项列表里。模板是「参数骨架」，不是可直接运行的工作流。
2. **执行前由插件替换**：`substitute()`（`__init__.py:204`，正则 `__zx:(\w+)__`），参数来源三层：`VISIBLE_PARAMS` 默认 → `TEMPLATE_DEFAULTS` → 请求体 `params`。
3. **真实 `/zeroexo/v1/last-prompt` 取证**（5609 B，node 12 `ZeroExoRefVideo`）：
   width 992 / height 416 / frames 294 / steps 8 / cfg 1 / seed 1473010218 / frame_rate 24 /
   guide_frames 22 / sampler `res_multistep` / scheduler `simple` / shift_video 12 / shift_audio 3 /
   cache_frames_codec `raw` —— **全部是真实数值**，没有 NaN 下发。
4. **发现一个真 bug**：`use_prev_guide` 既不在 `TEMPLATE_DEFAULTS` 也不在 `VISIBLE_PARAMS`，前端也不下发 →
   替换后留下字面量 `"__zx:use_prev_guide__"`。该输入是 `BOOLEAN`（`ref_video.py:99`），
   字符串不满足 ComfyUI 布尔校验，属于「要么直接校验失败、要么不被当 bool 用」的脏数据。
   而 `ref_video.run()` 里这个开关**从头到尾没被消费**（全文件只出现 3 次：docstring、INPUT_TYPES、形参），
   实际引导走 `guide_in_path`，所以补 `False` 不改变任何出片行为。

## 改动

- `TEMPLATE_DEFAULTS` 补 `"use_prev_guide": False`（注释写明当前 `run()` 不消费、引导靠 `guide_in_path`）。
- `submit_job`（`__init__.py:963` 替换之后）与 `_prepare_batch_segment`（`:1227` 之后）各加硬守卫：
  替换后仍命中 `__zx:<name>__` → 单条路径 `400` + 点名缺哪个键；批次路径 `RuntimeError` 点名。
  **不静默带垃圾值排队**（延续「不许静默降级」）。
- 新增 `comfyui-plugin/tests/test_template_placeholders.py`（AST 解析源码，不 import 插件）：
  ① 模板 32 个占位符必须都能在 `TEMPLATE_DEFAULTS` / `*_VISIBLE_PARAMS` 找到默认值（唯一豁免运行期赋值的 `guide_path`）；
  ② `use_prev_guide` 必须在 `TEMPLATE_DEFAULTS`（本条回归）；
  ③ 禁止 `__zx` 类拼错写法。3/3 通过。
- 版本 bump 0.1.6：`__init__.py` `PLUGIN_VERSION`、`src/features/canvas-tabs/plugin-version.ts`；
  重打 `public/downloads/ComfyUI_ZeroExoNodes-0.1.6.zip`（437812 B，抽检含版本号/默认值/守卫）。
- 顺手修 `tools/build-plugin-zip.mjs`：本机没有 `powershell.exe`（只有 pwsh 7），`execFileSync('powershell')` 报 ENOENT，
  改成探测 `pwsh` → 回退 `powershell`。
