# C-27 版本号归位：从左下浮层胶囊 → 页脚内联文本

日期：2026-11-22
用户反馈（截图）：主页左下角 `v0.4.45` 压在「第一次使用？先完成…」这行文字左端，位置与样式都不对。

## 现状/根因
`canvas-page.tsx` 用 `position: fixed; left: 12; bottom: 46` 把 `VersionBadge` 悬浮在页面上，
而底部 `OnboardingNotice` 条的文字从 `padding-left: 20` 开始 —— 两者在视觉上挤在同一行左侧；
`VersionBadge` 的按钮是 24px 高的圆角胶囊（10px 字 + 1px 边框），与页脚 12px 纯文本不是一套语言。

## 修法
- `VersionBadge` 增加 `variant?: 'chip' | 'inline'`（默认 `chip`，编辑器页保持现有胶囊不动）：
  `inline` 时去掉边框/背景/圆角胶囊，11px、muted 色、与页脚文本同级，点击仍弹同一张版本对照 Popover。
- `OnboardingNotice` 增加可选 `versionSlot`，放在右侧「打开使用指引」之前，成为页脚的一部分
  （`提示文字 … ｜ v0.4.45 ｜ 打开使用指引`），不再用 fixed 浮层。
- `canvas-page.tsx` 删除 fixed 包裹层，改为 `<OnboardingNotice versionSlot={<VersionBadge variant="inline" />} />`。

## 验收
- 主页版本号位于页脚右段、与「打开使用指引」同一行，不覆盖左侧提示文字。
- 点击仍弹出「网页本地 / 官方最新 / MCP 本地」对照，`data-version-badge` 保留（原有选择器不变）。
- 编辑器页不受影响（仍 chip）。
- `tsc --noEmit` 零错误。
