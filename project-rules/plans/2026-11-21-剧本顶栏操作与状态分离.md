# C-17 剧本顶栏拆分：操作按钮归左，右侧只做状态栏

日期：2026-11-21
用户口径（原话）：「这是剧本的工具栏，很显然他现在和状态栏混用了，把右边非状态按钮移动到左侧！！！」

## 改前
- 左：集数下拉 / 导入 / 撤销 / 重做 / 版本
- 右：显示标签（操作）· 问AI（操作）· 字数 · 总页数 · 总时长（统计）

操作和统计混在一个右容器里，状态栏里出现可点按钮。

## 改后
- 左（`data-toolbar-zone="left"`）：集数下拉 / 导入 / 撤销 / 重做 / 版本 ｜分隔线｜ 显示标签 / 问AI
- 右（`data-script-stats`）：只有 字数 · 总页数 · 总时长（纯文本，无按钮）
- 新增 `data-script-toggle-labels` 便于定位「显示标签」按钮。
