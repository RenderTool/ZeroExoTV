# 导演台导轨拖拽规格（2026-11-04 实时预览版，唯一判定来源）

1. 仅普通模式可拖；批量勾选、段间衔接、只读轨一律不启动拖拽。
2. pointerdown 起算，位移 ≤4px 视为点击（走原选中逻辑），>4px 才进入拖拽。
3. 拖起后被拖片段 = 浮层幽灵跟随指针：保持抓取点偏移、scale(1.04)、投影、半透明 0.7、zIndex 10、cursor grabbing（与剧本主体条目的鬼影同一手法）。
4. 拖动中其余片段**实时让位**：按预览顺序渲染（占位框把让位片段以 transform 推开，过渡约 120ms），拖动期间屏幕呈现的就是松手后的排列。
5. 预览落点唯一判定 = computeInsertIndex 中点归属（左半→前，右半→后）；指针距当前缝线 ≤8px 不换边；预览跟手即时更新，禁止 100ms 防抖迟滞。
6. 预览位置渲染整段占位框（宽 = 被拖片段宽，storyboard 同款虚线占位），不允许只剩 2px 插入线；旧 [data-drop-line] / [data-drag-placeholder] 覆盖层已移除。
7. 滚动：仅当指针距容器左右缘 <24px 时按 12px/次固定步进自动横滚；幽灵位移含滚动补偿（content 坐标系）。
8. Esc / 窗口失焦 / pointercancel = 取消，不提交、恢复原顺序；预览态即刻清零。
9. pointerup = 提交当前预览顺序唯一一次（落点 === 预览位置）；原位（index === from 或 from+1）不提交。
10. 提交后抑制紧随的 click/pointerup 选中（capture 阶段 stopPropagation），避免松手误选中。
11. 拖拽全程片段 left/width 与刻度对齐不变（只换序，让位走 transform）；结束（提交或取消）后 DOM 残留 = 0。
12. 出片页（非 zeroBaseRail）路径不受本规格影响，旧行为原样。
